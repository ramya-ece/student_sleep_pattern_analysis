# Student Sleep Pattern Analysis

A data analysis project examining student sleep patterns and their correlation with academic performance using Excel. The analysis includes data visualization, statistical testing, and actionable insights for improving student well-being.

## Project Overview

### Dataset Features
- Sleep duration (hours)
- Sleep quality (1-10 scale)
- Bedtime and wake-up times
- Academic performance metrics
- Study hours
- Screen time before bed
- Caffeine consumption
- Exercise habits
- Stress levels

### Analysis Components
- Descriptive statistics
- Correlation analysis
- Trend identification
- Pattern visualization
- Hypothesis testing
- Regression analysis
- Sleep quality scoring

## Excel Features Used

### Data Analysis Tools
- Pivot Tables
- VLOOKUP/HLOOKUP
- Statistical Functions
- Data Validation
- Conditional Formatting
- Charts and Graphs
- Power Query
- Excel Formulas

### Visualizations
- Sleep duration distribution
- student age and gender
- Sleep quality trends
- Academic performance correlation with sleep
- age and study pattern analysis
- fitness and sleep with age filter
- screen time and caffiene intake levels
- Daily pattern charts
